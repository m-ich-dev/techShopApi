# Definition of Done

Перед тем как сообщить пользователю, что задача выполнена, агент проверяет каждый пункт:

- [ ] Нет нового использования `@ts-ignore`, `console.log`, `console.error`, `console.warn`.
- [ ] Новое использование `any` отсутствует в прикладном коде.
- [ ] Если `any` использован в инфраструктурном коде, это обусловлено ограничениями TypeScript или сторонней библиотеки и сопровождается кратким комментарием.
- [ ] Используются существующие миксины/типы/утилиты, а не созданы новые аналоги.
- [ ] Бизнес-логика только в Service, SQL/запросы только в Repository, HTTP только в Controller.
- [ ] Ошибки — через `HTTPError` с существующей или явно согласованной фабрикой, не через `Error`.
- [ ] Валидация входных данных — через Request/zod, не вручную в контроллере или сервисе.
- [ ] Сериализация ответа — через Resource, не вручную в контроллере.
- [ ] Если менялось больше одной записи в БД за операцию — обёрнуто в транзакцию Kysely.
- [ ] Новая сущность (если создавалась) зарегистрирована в соответствующем DI-контейнере.
- [ ] Миграции (если требовались) — новые файлы, существующие не редактировались задним числом.
- [ ] Тесты, связанные с изменённой логикой в Service, актуальны и не удалены/отключены без причины.
- [ ] Изменения ограничены задачей — не выполнен посторонний рефакторинг или переименование.
- [ ] Ответ пользователю дан на русском языке, сообщения коммитов (если создавались) — на английском в формате Conventional Commits.
- [ ] Если добавлен/изменён роут — обновлена OpenAPI-документация
      (paths-файл в src/boot/docs/paths/, docs-schema при необходимости)

Если хотя бы один пункт не выполнен — сообщи об этом явно, не скрывай отклонение от правил.
